Publish approved updates

  1. Open the approved page’s preview (Open preview in the queue).
  2. Click Publish in Sidekick. It is only enabled for the publish role; advisors see it greyed out.
  3. The live site updates worldwide in seconds, and the Published event is added to the audit log.

Publishing many pages at once (for example a new site launch): select the documents in Google Drive and use Sidekick’s bulk Publish.

Enforced by the platform: the Admin API rejects a publish from any account without the publish role, whether it comes from Sidekick, a script or a bookmark.

Roles and permissions

Advisor: author role

Edit, preview, delete their drafts and request reviews. Cannot publish or change site configuration.

Supervisor: publish role

Everything an advisor can do, plus publish and unpublish, review snapshots and bulk publishing.

Platform admin: admin role

Site configuration, roles, new sites and integrations. MarTech Engineering and the platform owner.

Roles are set once in the site’s access configuration (docs/access-admin.json in the repository) and enforced by the platform for every request.
