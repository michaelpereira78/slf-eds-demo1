Capability 7: compliance review

Compliance review queue

Pages waiting for review, with their preview links. Approving a page lets it be published; requesting changes sends it back to the advisor with a note.

Review queue

How it works in production

  1. The advisor edits the page and clicks Preview. The preview shows a status bar: Not yet approved.
  2. The advisor clicks Request review (in the status bar, in Sidekick, or on the advisor workspace). The page joins this queue and the submission is written to the audit log.
  3. The supervisor and Compliance check the preview and click Approve or Request changes. For a locked, exact-version approval the supervisor can add the page to a review snapshot (Sidekick > Review), which needs the publish role.
  4. Only supervisors (the publish role) can publish. Advisors have the author role: they can edit and preview, and Sidekick shows Publish greyed out. The platform rejects a publish from an author account, so this is enforced, not just hidden.
  5. Each submission, approval, request for changes and publish is added to the compliance-audit-log Google Sheet for audits.

In this demo, Approve and Request changes are saved in this browser only, so you can click through the flow safely. Reset the demo with the button above the queue.
