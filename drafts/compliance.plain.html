Capability 7: compliance review

Compliance review queue

Pages waiting for review, with their preview links. Approving a page lets it be published; requesting changes sends it back to the advisor with a note.

Review queue

How it works in production

  1. The advisor edits the page and clicks Preview. The preview shows a status bar: Not yet approved.
  2. The advisor clicks Request review (in the status bar or in Sidekick). Using Sidekick’s Review button, the page goes into a review snapshot, which locks that exact version.
  3. Compliance opens the review link, checks the page and clicks Approve or Reject in the snapshot tool. Approve publishes that locked version; Reject unlocks it with notes for the advisor.
  4. Only people in the Compliance publisher role can publish. Advisors can edit and preview, but the Publish button is not available to them.

In this demo, Approve and Request changes are saved in this browser only, so you can click through the flow safely. Reset the demo with the button above the queue.
