Starting a page from a template

  1. Open the Approved templates folder in Drive (tools/sidekick/templates).
  2. Right-click the template and choose Make a copy, then move the copy to your site folder and rename it.
  3. Replace the text in square brackets, then click Preview in Sidekick.
  4. Or, inside any document: Sidekick, Library, Blocks, then pick a template and paste it.

Adding a new approved template

A developer adds a folder under templates/ in the code (a CSS file, and a JavaScript file if needed), registers its name, and adds a starter document. Existing sites are not affected until an author chooses the new template. See ADD-A-TEMPLATE.md in the repository.
